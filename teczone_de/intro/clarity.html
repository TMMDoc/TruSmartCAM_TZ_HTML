Die Benutzeroberfläche

Die Benutzeroberfläche

TecZone verfügt über eine moderne Benutzeroberfläche, die den Arbeitsbereich übersichtlich und leicht verständlich gestaltet. Statt alle Befehle gleichzeitig anzuzeigen, blendet die Oberfläche die Werkzeuge und Einstellungen ein, die für das aktuell ausgewählte Element relevant sind.

In der Benutzeroberfläche von TecZone finden Sie nicht:

  • Viele Zeilen mit übereinandergestapelten Symbolen, von denen im aktuellen Kontext nur wenige relevant sind.

  • Verschachtelte Menüs mit Dutzenden von Befehlen.

  • Benutzeroberflächen-Multifunktionsleisten, die am oberen Bildschirmrand viel Platz einnehmen.

Stattdessen folgt die Oberfläche einem einfachen Prinzip: Auswählen, dann Bearbeiten.

  • Wählen Sie ein Element durch Anklicken aus.

  • Ein Bedienfeld wird geöffnet und zeigt die für das ausgewählte Element verfügbaren Einstellungen und Aktionen an.

  • Das Bedienfeld kann Steuerelemente enthalten, mit denen Sie die Auswahl auf weitere ähnliche Elemente erweitern können.

  • Das Bedienfeld kann auch Steuerelemente zum Navigieren zwischen verwandten Elementen enthalten.

Diese Prinzipien gelten in allen Arbeitsmodi von TecZone. Ob Sie ein 3D-Modell bereinigen, Teile auf einer verschachtelten Blechtafel anordnen oder Abkantwerkzeuge bearbeiten – Sie arbeiten stets mit denselben Grundkonzepten.

Die folgenden Abschnitte veranschaulichen diese Konzepte anhand von Beispielen aus dem Berichtseditor von TecZone Bend.

Ein geführter Rundgang

Dieser kurze Rundgang stellt die Benutzeroberfläche vor. In TecZone kommen immer wieder dieselben grundlegenden Konzepte zum Einsatz. Wenn Sie diese kennen, können Sie die meisten Bereiche der Anwendung mit nur wenig zusätzlicher Schulung leichter nutzen.

Ein Beispielbericht

Weitere Informationen zum Erstellen und Bearbeiten von Berichtsvorlagen finden Sie in einem späteren Abschnitt. Zunächst helfen die folgenden Begriffe rund um Berichte dabei, die Konzepte der Benutzeroberfläche zu veranschaulichen.

Das obige Bild zeigt verschiedene Elementtypen, die in einem Bericht verwendet werden können.

  • Ein Beschriftung enthält Text. Sie können Eigenschaften wie Schriftart, Textausrichtung und Farbe festlegen.

  • Ein Feld zeigt Daten an, die aus dem zugrunde liegenden Bauteil abgerufen werden.

  • Ein Form ist ein einfaches geometrisches Element, etwa eine Ellipse, ein Rechteck oder eine Linie. Es kann in einem Bericht als Hintergrund, Hervorhebung oder Trennlinie dienen.

  • Eine Tabelle zeigt tabellarische Daten an, die aus dem zugrunde liegenden Bauteil abgerufen werden. In diesem Beispiel listet die Tabelle die Biegeoperationen des Bauteils auf und zeigt ausgewählte Eigenschaften für jede Operation an.

Mit diesen Grundlagen können wir uns die Benutzeroberfläche nun in der Anwendung ansehen.

Prinzip: Element anklicken, um es zu bearbeiten

Klicken Sie auf ein Feld. Daraufhin wird ein Bedienfeld geöffnet, über das Sie das ausgewählte Element anzeigen und bearbeiten können. Hier sehen Sie ein kommentiertes Beispiel:

Wenn Sie auf ein Feld klicken, wird es ausgewählt und ein Bedienfeld zum Bearbeiten geöffnet. Das Bedienfeld enthält mehrere gängige Elemente der Benutzeroberfläche:

  • Über die Titelleiste können Sie das Bedienfeld verschieben. Klicken Sie dazu an eine beliebige Stelle auf den Hintergrund des Bedienfelds und ziehen Sie es an die gewünschte Position. Wenn Sie die Option Anheften aktivieren, bleibt das Bedienfeld an dieser Position verankert. Andernfalls wird es in der Nähe des Mauszeigers geöffnet.

  • Eingabefelder, Zahlenfelder, Auswahllisten, Schriftartauswahlen und Ausrichtungsoptionen bieten verschiedene Möglichkeiten, die Feldeinstellungen anzuzeigen und zu ändern.

  • Aktionsschaltflächen führen Aktionen für das ausgewählte Element aus. Beispielsweise können Sie das Feld aus dem Bericht entfernen, indem Sie auf die Schaltfläche Löschen klicken.

  • Bedienfelder können viele Steuerelemente enthalten. Damit sie übersichtlich bleiben, werden zusammengehörige Einstellungen in Abschnitten gruppiert, die Aufklappbereiche heißen. Im obigen Beispiel ist der Aufklappbereich Darstellung geschlossen, während der Bereich Schriftart geöffnet ist. Klicken Sie auf einen Aufklappbereich, um ihn zu öffnen oder zu schließen.

Prinzip: Mehrere Elemente auswählen und gemeinsam bearbeiten

Sie können weitere Elemente auswählen, indem Sie beim Anklicken die Taste Shift gedrückt halten. Sind mehrere Elemente ausgewählt, zeigt das Bedienfeld die Einstellungen an, die für alle ausgewählten Elemente bearbeitet werden können.

Im obigen Bild wurden mit Shift+Klick drei Felder ausgewählt. Im Bedienfeld können ihre gemeinsamen Einstellungen zusammen bearbeitet werden. In diesem Beispiel ist der Aufklappbereich Darstellung geöffnet und der Aufklappbereich Schriftart geschlossen.

Nach dem Ändern der Einstellungen Hintergrundfarbe und Linienbreite sieht der Bericht wie folgt aus:

Die Änderungen werden auf jedes ausgewählte Element angewendet. Beachten Sie, dass die Einstellung Ausdruck im Bedienfeld für die Mehrfachbearbeitung nicht angezeigt wird. Einstellungen, die normalerweise für jedes Element unterschiedliche Werte haben, werden ausgeblendet, weil ein gemeinsamer Wert in der Regel nicht sinnvoll wäre. Beispielsweise sollen normalerweise nicht drei Felder denselben Wert aus dem Bauteil anzeigen.

Prinzip: Verschiedene Elementtypen gemeinsam bearbeiten

Sie können gleichzeitig Elemente unterschiedlichen Typs auswählen. Das Bedienfeld zeigt dann nur die Einstellungen und Aktionen an, die allen ausgewählten Elementen gemeinsam sind.

Das folgende Beispiel zeigt das Bedienfeld für ein Element vom Typ Form:

Wenn Sie ein Feld und ein Form gemeinsam auswählen, ändert sich das Bedienfeld wie unten dargestellt:

  • Die Titelleiste zeigt 2 Berichtselemente an, da es sich bei den ausgewählten Elementen um Berichtselemente handelt, auch wenn sie unterschiedlichen Typen angehören.

  • Angezeigt werden nur die Einstellungen, die Feld und Form gemeinsam haben. In diesem Beispiel befinden sich die gemeinsamen Einstellungen im Abschnitt Darstellung.

Prinzip: Bei einer Mehrfachauswahl können zusätzliche Aktionen verfügbar sein

Eine Mehrfachauswahl kann mehr als gemeinsame Einstellungen bieten. Je nach den ausgewählten Elementen zeigt das Bedienfeld möglicherweise auch Aktionen an, die bei der Auswahl eines einzelnen Elements nicht verfügbar sind.

Das folgende Beispiel stammt aus der Biegeansicht. Wenn Sie auf eine Biegung klicken, wird ein Bedienfeld geöffnet, in dem Sie ihre Einstellungen bearbeiten und Aktionen für sie ausführen können:

Für die beiden ausgewählten Biegungen lassen sich mehrere gemeinsame Einstellungen bearbeiten. Dazu gehört, ob die Biegung übersprungen wird und welche Station verwendet wird. Außerdem ist jetzt eine neue Schaltfläche Gruppieren verfügbar. Da die beiden Biegungen auf einer Linie liegen, können sie zu einer einzigen Biegeoperation zusammengefasst werden. Diese zusätzliche Aktion ist nur verfügbar, wenn die Voraussetzungen für die Mehrfachauswahl erfüllt sind.

Wenn Sie auf die Schaltfläche Gruppieren klicken, werden die Biegungen wie unten dargestellt zusammengefasst:

Das Bauteil enthält nun drei Biegeoperationen. Biegung 3 ist eine gruppierte Biegung. Deshalb wird im Bedienfeld eine neue Schaltfläche Gruppierung aufheben angezeigt, mit der Sie die Gruppierung wieder aufheben können.

Prinzip: Mit dem Teilbereich „Auswahl“ die Auswahl ändern

Ein Bedienfeld enthält häufig im unteren Bereich einen Teilbereich Auswahl. Er bietet Befehle zum Ändern der aktuellen Auswahl. Meist können Sie damit Elemente hinzufügen, die ein relevantes Merkmal mit dem ausgewählten Element gemeinsam haben.

Zu den verfügbaren Befehlen können beispielsweise gehören:

  • Alle Felder in einem Bericht auswählen.

  • Alle Biegefelder auswählen.

  • Alle Polylinien auf der aktuellen Ebene auswählen.

  • Alle Stanzungen auswählen, bei denen dasselbe Stanzwerkzeug verwendet wird.

  • Alle Biegungen auswählen, die mit derselben Einrichtung ausgeführt werden.

Das folgende Beispiel zeigt einen Teilbereich „Auswahl“ im Berichtseditor:

Der Teilbereich „Auswahl“ hat einen charakteristischen gemusterten Hintergrund und abgerundete Schaltflächen. In diesem Beispiel können Sie über die Schaltflächen Alle Felder und Alle Biegefelder auswählen oder mit Toggle die aktuelle Auswahl umschalten.

Welche Auswahlbefehle verfügbar sind, hängt vom aktuellen Kontext ab. Sie erleichtern häufig benötigte Auswahlvorgänge.

Prinzip: Mit dem Teilbereich „Navigation“ durch die Elementhierarchie navigieren

Die Elemente in einem Bauteil, Bericht oder Layout sind häufig hierarchisch angeordnet. Diese Struktur wird als Elementbaum bezeichnet. Sie wird üblicherweise als umgedrehter Baum dargestellt: Das übergeordnete Element steht oben, die untergeordneten Elemente darunter.

Wenn Sie auf die Tabelle klicken, enthält das Bedienfeld Steuerelemente zum Navigieren durch diese Hierarchie:

Der Teilbereich „Navigation“ enthält Richtungsschaltflächen, mit denen Sie sich durch den Elementbaum bewegen können. Wie der Teilbereich „Auswahl“ hat er einen charakteristischen strukturierten Hintergrund und befindet sich im unteren Bereich des Bedienfelds, oberhalb des Teilbereichs „Auswahl“.

Mit den Schaltflächen Vorheriges und Nächstes wechseln Sie zwischen Elementen auf derselben Ebene des Elementbaums. Auf der Tabellenebene können Sie damit andere Elemente im Bericht auswählen, beispielsweise die Elemente Beschriftung oder Feld.

Wenn Sie auf die Schaltfläche Bericht klicken, wechseln Sie von der Tabelle zu ihrem übergeordneten Element, dem Bericht. Das Bedienfeld für den Bericht enthält Einstellungen wie Papierformat und Seitenränder:

Der Bericht ist die Wurzel des Elementbaums. Daher gibt es keine übergeordnete Ebene, zu der Sie navigieren könnten. Der Teilbereich „Navigation“ enthält deshalb nur eine Schaltfläche: Elemente. Damit wechseln Sie zur Liste der Berichtselemente. Wenn Sie darauf klicken, wird wieder die Tabelle ausgewählt.

Von der Tabelle aus wechseln Sie mit der Schaltfläche Spalten eine Ebene nach unten in den Spaltenbearbeitungsmodus. Wenn Sie auf die Schaltfläche Spalten klicken, werden die Einstellungen der ausgewählten Tabellenspalte angezeigt:

Auf Spaltenebene wechseln Sie mit den Schaltflächen Vorheriges und Nächstes zwischen den Spalten der Tabelle. Da die Spalten in diesem Beispiel die unterste Ebene bilden, gibt es keine Schaltfläche zum Navigieren nach unten. Mit der Schaltfläche Tabelle wechseln Sie eine Ebene nach oben und kehren zur Bearbeitung der Tabelle zurück.

Zusammenfassung

  • Klicken Sie auf ein Element, um es zu bearbeiten.

  • Wählen Sie mehrere Elemente aus, um ihre gemeinsamen Einstellungen zusammen zu bearbeiten.

  • Wählen Sie Elemente unterschiedlichen Typs aus, um die Einstellungen zu bearbeiten, die sie gemeinsam haben.

  • Nutzen Sie die Mehrfachauswahl, um zusätzliche Aktionen aufzurufen, sofern die ausgewählten Elemente diese unterstützen.

  • Ändern Sie die aktuelle Auswahl effizient über den Teilbereich „Auswahl“.

  • Navigieren Sie über den Teilbereich „Navigation“ durch den Elementbaum.
